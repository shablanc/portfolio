01 · 게임 커뮤니티 툴

리그오브레전드 밴픽 시스템

React Vercel 실시간 인터랙션
+

실제 토너먼트 팀들이 사용하는 실시간 밴픽 드래프트 사이트. 게임 챔피언 데이터를 기반으로 팀별 밴픽 진행을 관리하고 시각화합니다. Fearless 룰(이미 픽한 챔피언 재사용 금지)을 지원하는 특화 기능을 포함합니다.

실시간 밴픽 순서 관리, 챔피언 검색·필터, Fearless 룰 적용, 팀별 결과 시각화

React, Vercel 배포, 챔피언 이미지 CDN 연동

게임 커뮤니티의 구체적인 니즈를 발견하고 직접 기획·개발·배포까지 완성한 도메인 특화 서비스

02 · 경매 시스템

선수 드래프트 경매 플랫폼

GitHub Pages 경매 로직 상태 관리
+

토너먼트 리그에서 선수를 경매 방식으로 드래프트하는 시스템. 예산 관리, 입찰 경쟁, 선수 매물 풀 관리 등 복잡한 경매 비즈니스 로직을 인터랙티브 UI로 구현해 실제 리그 운영에 활용 중입니다.

팀별 예산 관리, 선수 매물 풀 뽑기, 실시간 입찰, 드래프트 결과 정산

JavaScript, GitHub Pages 배포, 복잡한 상태 관리 로직

복잡한 규칙 체계를 논리적으로 설계하고 시스템으로 구현 — 비즈니스 로직 설계 능력 증명

03 · 헬스케어 앱

운동 트래킹 앱 — Fitlog

React Firebase Firestore 실사용자 운영 중
+

멤버·트레이너 다중 역할을 지원하는 운동 관리 앱. 루틴 설정, 일일 체크리스트, 운동 다이어리, 캘린더 기록, 실시간 트레이너 피드백까지 — 실제 사용자(멤버 2명 + 트레이너)가 매일 사용 중인 live 서비스입니다.

멤버/트레이너 권한 분리, 루틴 설정, 일일 체크리스트, 다이어리, 캘린더 스탬프, 실시간 피드백

React, Firebase Hosting, Firestore 실시간 DB, onSnapshot 리스너, base64 이미지 저장

기획부터 Firebase 풀스택 구현·배포까지 혼자 완성 — 실사용자가 있는 운영 중 서비스
